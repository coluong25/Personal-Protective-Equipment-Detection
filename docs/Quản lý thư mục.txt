data/ — dữ liệu thô, đã xử lý, bên ngoài
docs/ — tài liệu, báo cáo, hướng dẫn sử dụng
models/ — checkpoint và model đã huấn luyện xong
notebooks/ — EDA, thử nghiệm, trực quan hóa
outputs/ — biểu đồ, log, kết quả đánh giá
src/ — code production: data pipeline, model, utils
test/ — unit test và integration test



Dưới đây là chi tiết từng thư mục nên chứa gì:
data/ — dữ liệu, không được commit lên Git (thêm vào .gitignore)
    raw/ — dữ liệu gốc, không bao giờ chỉnh sửa trực tiếp
    processed/ — dữ liệu sau khi clean/transform
    external/ — dữ liệu từ nguồn bên ngoài (API, dataset public)

docs/ — tài liệu dự án
    Báo cáo kỹ thuật, thiết kế model, meeting notes
    API docs, hướng dẫn deploy

models/ — artifact của model (thường cũng gitignore, dùng DVC/MLflow)
    checkpoints/ — model lưu giữa các epoch
    final/ — model đã chọn để deploy

notebooks/ — Jupyter notebooks, chỉ để khám phá và trình bày
    Đặt tên theo thứ tự: 01_eda.ipynb, 02_feature_engineering.ipynb
    Không đặt code production ở đây

outputs/ — kết quả sinh ra từ quá trình train/eval
    figures/ — biểu đồ, confusion matrix, learning curve
    logs/ — training log, metrics
    reports/ — kết quả thực nghiệm

src/ — code production chính, có thể import như package
    data/ — data loading, preprocessing pipeline
    models/ — định nghĩa kiến trúc model
    training/ — train loop, loss, optimizer
    evaluation/ — metrics, evaluation script
    utils/ — helper functions dùng chung

test/ — kiểm thử
    unit/ — test từng function nhỏ
    integration/ — test toàn bộ pipeline
